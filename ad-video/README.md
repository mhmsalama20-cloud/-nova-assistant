## النسخة الأولى (انعملت عبر Higgsfield connector)

- **الصور الأولى:** `gpt_image_2_5` (high، 2k، 9:16). صورة مرجعية وحدة للأم والولد والجاكيت، وكل لقطة انولدت عليها عشان الوجوه والمنتج يضلّوا نفسهم.
- **الحركة:** `kling3_0` (std، 5 ثواني). S06 بصورة بداية ونهاية (الطاقية تحت ← فوق). S08 بالصوت (8 ثواني)، والجملة اتأكدت بالتفريغ: "Cozy, we're a little close, a lot cozy."
- **المونتاج:** على sandbox تبع Higgsfield بنفس منطق `stitch.py` و `make_endcard.py`، مع صوت مطر وهوا خفيف من S03 لآخر الفيديو.
- **النتيجة:** `cozy_ad_final_v2.mp4`، 36 ثانية، 1080×1920، بمشروع "Cozy ad - mother, baby and rain" على حساب Higgsfield.

## قبل ما تبلّش

1. **اسم المنتج والجملة الأخيرة:** موجودين بـ `shots.json` (`"product_name"`، `"dialogue"`، `"dialogue_language"`). إذا بدك الجملة بالعربي، غيّر `"dialogue"` وخلّي `"dialogue_language": "Levantine Arabic"`.
2. **الصور:** حطها بـ `refs/` (شوف [`refs/README.md`](refs/README.md)).
   صورة الأم وصورة الولد اللي بعثتهم صغار كتير (134×166 و 180×251 بكسل) — بهيك دقة الوجوه رح تطلع مش مطابقة. ابعت النسخ الأصلية بأعلى دقة عندك.
3. **حقوق الصور:** إذا هدول صور ستوك أو أشخاص حقيقيين، تأكد إنه الرخصة بتسمح تستخدم وجوههم بإعلان معمول بالذكاء الاصطناعي. إذا لا، استخدم موديلات عندك موافقتهم، أو خلّي Higgsfield يولّد وجوه جديدة.

## الطريقة 1: بالسكربت (Higgsfield API)

```bash
cd ad-video
pip install -r requirements.txt
export HF_CREDENTIALS="key-id:key-secret"   # من cloud.higgsfield.ai (أو HF_KEY) — لا تحطه بأي ملف بالريبو

python generate.py --dry-run                 # بيطبع كل الطلبات بدون ما يصرف رصيد
python generate.py --stage keyframes         # 1) الصور الأولى لكل لقطة → output/keyframes/
#   شوف الصور: إذا وجه مش مطابق، عيد هاللقطة لحالها:
python generate.py --stage keyframes --only S05 --force
python generate.py --stage videos            # 2) حرّك كل صورة لفيديو → output/clips/
python stitch.py --endcard endcard.png --music music.mp3   # 3) الفيديو النهائي → output/final.mp4

# بطاقة النهاية جاهزة؛ لتعيدها بشعار أو نص تاني:
python make_endcard.py --tagline "a little closer, a lot cozier."
```

- **الموديلات:** بـ `shots.json` → `models`. موديل الصور (`keyframe`) لازم يقبل كذا صورة مرجعية، وموديل الفيديو (`video`) لازم يكون image-to-video. انسخ الـ id وأسماء الـ arguments من صفحة الموديل على cloud.higgsfield.ai، وجرّب بـ `--dry-run`.
  `"{image_urls}"` لحالها بتنحط كقائمة، و `"{duration}"` كرقم.
- **لقطة الحكي (S08):** بدها موديل بيطلّع صوت وحركة شفايف (lip-sync). حط له موديل خاص جوّا اللقطة نفسها:
  `"video_model": {"id": "...", "args": {...}}` — وباقي اللقطات بتضل عالموديل العام.
- **الثبات بين اللقطات:** كل لقطة بتاخد صورة الأم/الولد/المنتج، وكمان صورة لقطة سابقة (`"@S01"`) عشان اللبس والشارع والإضاءة يضلّوا نفسهم.
- **وضع الـ Agent:** `python generate.py --mode agent` بيبعت السيناريو كامل مع الصور لـ Higgsfield Agent وهو بيختار الموديلات لحاله (بدها صلاحية Agent API بحسابك).

## الطريقة 2: يدوي على موقع Higgsfield

1. **ثبات الوجوه:** إذا عندك 10–20 صورة للأم، اعمل لها **Soul ID / Character**. إذا عندك صورة وحدة بس، استخدم موديل صور بيقبل صور مرجعية (Edit / Reference) وارفع صورة الأم + الولد + المنتج مع كل لقطة.
2. **الصور الأولى:** لكل لقطة، الصق برومبت `keyframe` من `shots.json` (بعد ما تبدّل `{mother}` `{baby}` `{product}` `{location}` بالنصوص اللي بـ `blocks` — أو انسخها جاهزة من `python generate.py --dry-run`). اختار 9:16.
3. **الفيديو:** افتح Create Video → Image-to-Video، ارفع الصورة، والصق برومبت `motion`. للقطات اللي فيها تغيّر بالملامح (S03، S04، S07) اختار موديل قوي بالوجوه، ولو الموديل بيقبل صورة بداية وصورة نهاية، استخدمها.
4. **S08:** موديل فيديو بصوت، أو ولّد الفيديو ساكت واستخدم أداة Lip-sync/Speak مع تسجيل صوت للجملة.
5. نزّل المقاطع بأسماء `S01.mp4 … S08.mp4` بـ `output/clips/` وشغّل `python stitch.py --endcard endcard.png`.

## نصائح عشان يطلع واقعي

- ولّد **3–4 نسخ** من كل صورة أولى واختار أحسن وحدة قبل ما تحرّكها — الفيديو بيورث كل غلطة بالصورة.
- اللقطات اللي فيها إيدين (S06) أصعب شي — إذا الأصابع خربت، عيدها، أو صغّر الحركة.
- خلّي المطر "نتفة" (drizzle)، المطر القوي بيطلع مزيّف.
- إذا ملامح الزعل طلعت مبالغ فيها، شيل كلمات زي `crying` وخليها `about to cry` / `worried`.
