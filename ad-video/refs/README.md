# الصور المرجعية

حط الصور هون بهالأسماء بالزبط (أو غيّر المسارات بـ `shots.json` → `references`):

| الملف | شو هو |
|---|---|
| `mother.png` | صورة وجه الأم — أوضح وأكبر صورة عندك (1024px أو أكثر) |
| `baby.png` | صورة وجه الولد — كمان بدقة عالية |
| `product.webp` | صورة المنتج (الجاكيت أبو جيبة البيبي) |

الصور مش مرفوعة على git عن قصد (`.gitignore`) لأنها صور أشخاص.
