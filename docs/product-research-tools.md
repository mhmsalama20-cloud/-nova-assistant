# أدوات بحث المنتجات مع Claude Code

آخر تحديث: أكتوبر 2026

## 1. السكيل الموجود في هذا المشروع

المسار: `.claude/skills/product-research/`

يشتغل تلقائياً لما تطلب من Claude Code داخل هذا المشروع شي مثل الأمثلة تحت، أو لما تبدأ رسالتك بـ `/product-research`:

- "دورلي على منتجات رابحة للدروبشيبنج على شوبيفاي في السعودية، ميزانيتي 500 دولار"
- "حلل هذا المنتج: <رابط>"
- "شو بيبيع هذا المتجر؟ <رابط متجر منافس>"

شو بيعمل:

1. يسألك سؤال واحد عن المنصة والبلد والميزانية إذا كانت ناقصة.
2. يجمع منتجات مرشحة من أكثر من مصدر: قوائم الأكثر مبيعاً في أمازون ونون، إعلانات فيسبوك وتيك توك، متاجر شوبيفاي المنافسة، والموردين.
3. يستبعد المنتجات الخطرة أو الممنوعة أو اللي ما فيها ربح.
4. يحسب الربح بالآلة الحاسبة `scripts/profit.py`، ويعطي كل منتج علامة من 100.
5. يعطيك جدول مرتب، وكل رقم معه رابط مصدره.

قاعدة مهمة في السكيل: ممنوع يخترع أرقام. إذا ما قدر يفتح موقع، بيقلك، وبيستخدم بحث الويب أو بيطلب منك صورة شاشة بدل ما يخمّن.

### وين لازم يكون السكيل حتى يشوفه Claude Code

- **على الويب أو الجوال (جلسات السحابة):** كل جلسة بتنسخ المشروع من GitHub، وبتشوف بس الفرع اللي مختاره من قائمة الفروع (عادةً `main`). تأكد إن هذا الفرع فيه المجلد `.claude/skills/product-research/`.
- **على جهازك:** افتح Claude Code داخل مجلد المشروع، والسكيل بيشتغل لحاله.
- **للتأكد:** اسأل Claude: "شو السكيلز المتوفرة عندك؟" ولازم يطلع `product-research`.

### الآلة الحاسبة لحالها

شغّلها من مجلد المشروع:

```bash
python3 .claude/skills/product-research/scripts/profit.py --price 39.99 --cost 8.5 --shipping 4 --cpa 12
```

- `--price` سعر البيع
- `--cost` سعر المنتج من المورد
- `--shipping` تكلفة الشحن عليك
- `--cpa` تكلفة الإعلان لكل عملية بيع

بتعطيك صافي الربح، وأعلى مبلغ بتقدر تدفعه للإعلان (break-even CPA)، وأقل عائد إعلاني لازم يحققه الإعلان حتى ما تخسر (break-even ROAS).

| [nexscope-ai/Amazon-Skills](https://github.com/nexscope-ai/Amazon-Skills) | ✅ جيدة | رخصة MIT. سكيلز مفصلة (حوالي 300 سطر) لبحث منتجات أمازون والنيشات والترندات، بدون سكربتات. فيها دعاية لمنتج الشركة المدفوع، فتجاهلها. |

| [noique/cross-border-ecommerce-skills](https://github.com/noique/cross-border-ecommerce-skills) | ⚠️ للاطلاع فقط | معظم نصوصها بالصيني ومكتوبة لبائعين من الصين بيبيعوا لأمريكا وأوروبا، فصعب تقرأها وتتأكد منها قبل التركيب. ورخصتها CC BY-NC، يعني لغير الاستخدام التجاري. |
| [FlatNineOrg/ecommerce-skills](https://github.com/FlatNineOrg/ecommerce-skills) | ❌ لا أنصح فيها الآن | تحتاج مفتاح API من خدمة Cart، والمستودع صغير وفيه commit واحد بس. |

إذا بدك تضيف سكيلز أمازون من Nexscope لجهازك بس (الأمر بيحتاج يكون Node.js مثبت عندك):

```bash
npx skills add nexscope-ai/Amazon-Skills --skill amazon-product-research -g
npx skills add nexscope-ai/Amazon-Skills --skill amazon-niche-finder -g
npx skills add nexscope-ai/Amazon-Skills --skill amazon-trending-products -g
```

انتبه: `-g` بيحط السكيلز بمجلد `~/.claude/skills` على جهازك، وجلسات السحابة ما بتقرا هذا المجلد. إذا بدك سكيل يشتغل بالسحابة، اطلب من Claude بجلسة سحابة يضيفه لمجلد `.claude/skills/` بالمشروع ويرفعه على GitHub.

قاعدة عامة: أي سكيل من الإنترنت، افتح ملف `SKILL.md` واقرأه قبل ما تركّبه، وانتبه لأي سكربت فيه.

## 3. أدوات بيانات (MCP) بتعطي أرقام أدق

السكيل بيشتغل من غير هذه الأدوات، باستخدام بحث الويب المدمج في Claude Code. بس هذه الأدوات بتعطيه أرقام حقيقية بدل التقديرات. ابدأ بدونها، وضيف وحدة بس لما تحس إنك محتاجها.

| الأداة | شو بتعطيك | السعر | رسمية؟ |
|---|---|---|---|
| [Apify](https://docs.apify.com/integrations/mcp) | آلاف السكرابرز الجاهزة: أمازون، علي إكسبرس، تيك توك شوب، جوجل ترندز | الدفع حسب الاستخدام | ✅ رسمية |
| [Helium 10 MCP](https://kb.helium10.com/hc/en-us/articles/51580564409883-Getting-Started-with-Helium-10-MCP) | بيانات أمازون: مبيعات تقديرية، كلمات مفتاحية، منافسين | بس بالخطط العالية (Diamond أو أعلى، تأكد من صفحتهم) | ✅ رسمية |
| [Jungle Scout MCP](https://www.junglescout.com/products/jungle-scout-mcp/) | بيانات أمازون: فئات، منافسين، أسعار، كلمات مفتاحية | مش ضمن اشتراك Jungle Scout العادي. بيشتغل مع منصة Cobalt المخصصة للشركات الكبيرة، والسعر بالتواصل مع المبيعات | ✅ رسمية |
| [Shopify Storefront Catalog MCP](https://shopify.dev/docs/agents/catalog/storefront-catalog) | البحث في كتالوج متجر شوبيفاي واحد | مجاني | ✅ رسمية |
| Google Trends MCP | اتجاه البحث على المنتج خلال السنين | مجاني | ❌ غير رسمية، ممكن تتعطل فجأة |
| TikTok Shop scrapers على Apify | أكثر المنتجات مبيعاً على تيك توك شوب | حوالي 4 إلى 5 دولار لكل 1000 نتيجة | ❌ من مطورين مستقلين |

مثال لإضافة Apify على Claude Code في جهازك (راجع صفحتهم للتأكد من الأمر):

```bash
claude mcp add --transport http apify https://mcp.apify.com
```

بعدها اكتب `/mcp` داخل Claude Code وسجّل دخول لحساب Apify. هذا الإعداد بينحفظ على جهازك بس، وما بيوصل لجلسات السحابة. للسحابة، ضيف Apify كـ connector من claude.ai (Customize ثم Connectors) بالرابط `https://mcp.apify.com`. الـ connectors بتشتغل بجلسات السحابة حتى لو الشبكة مقيدة.

ملاحظة: أرقام المبيعات اللي بتعطيها Helium 10 و Jungle Scout تقديرات من نماذجهم، مش أرقام رسمية من أمازون.

ترتيب الأولوية اللي بنصحك فيه:

1. **ابدأ بالسكيل لحاله.** ببلاش وبيكفي لتتعلم.
2. **إذا بدك أرقام أدق**، ضيف Apify وادفع حسب استخدامك.
3. **إذا قررت تبيع على أمازون بشكل جدي**، ساعتها بيستاهل اشتراك Helium 10 بخطة فيها MCP. أما Jungle Scout MCP فموجّه للشركات الكبيرة ومش مناسب للبداية.

## 4. ملاحظة عن جلسات Claude Code في السحابة

إعداد الشبكة الافتراضي بجلسات السحابة (Trusted) بيحجب مواقع التسوق: أمازون، علي إكسبرس، فيسبوك، جوجل ترندز، ريديت، ومتاجر شوبيفاي. بحث الويب المدمج بيضل شغال. إذا بدك السكيل يفتح هذه المواقع:

- إما تشغّل Claude Code على جهازك،
- أو توسّع الشبكة من إعدادات البيئة السحابية (مش من إعدادات حسابك): افتح قائمة البيئة بالجلسة واضغط Edit، ومن Network access اختار Custom، وضيف المواقع (مثلاً `*.amazon.sa`) مع تفعيل خيار "include default list"، أو اختار Full.

حتى بعد فتح الشبكة، مكتبة إعلانات ميتا وتيك توك Creative Center وجوجل ترندز غالباً بتحتاج تسجيل دخول أو بتحجب الزيارات الآلية، فالسكيل رح يطلب منك صورة شاشة.
