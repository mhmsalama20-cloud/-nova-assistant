# JUST RUN — موقع العلامة

موقع علامة ملابس للجري والتدريب. مبني بـ HTML و CSS و JavaScript بدون أي build step أو اعتماديات، فيشتغل من أي استضافة ملفات ثابتة.

## تشغيل المعاينة محلياً

```bash
cd المسار/إلى/المشروع
python3 -m http.server 8000
```

ثم افتح: <http://localhost:8000>

> ⚠️ لازم تفتح الموقع عبر خادم (http://) وليس بالنقر المزدوج على الملف (file://)، لأن صفحات المتجر تقرأ ملف المنتجات عبر `fetch` والمتصفح يمنع ذلك على `file://`. لو فتحته بالخطأ عبر `file://` ستظهر لك رسالة واضحة تشرح السبب.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية — هيرو، المجموعات، منتجات مختارة، قصة العلامة، بانر ختامي |
| `shop.html` | المتجر — شبكة منتجات مع تصفية حسب المجموعة وترتيب |
| `product.html` | صفحة المنتج (تقرأ `?id=` من الرابط) — معرض، مقاسات، ألوان، إضافة للسلة |
| `story.html` | قصتنا |
| `contact.html` | تواصل معنا |
| `cart.html` | السلة |

## وين تعدّل كل شي

### الألوان والمسافات وأحجام الخطوط
كلها في مكان واحد: **`assets/css/tokens.css`**

```css
--color-ink:    #111315;  /* أسود فحمي */
--color-paper:  #f6f5f1;  /* أبيض دافئ */
--color-lime:   #d5ff3f;  /* الأخضر الليموني — الأزرار والحواف المهمة */
--color-muted:  #62676b;  /* النصوص الثانوية */
--color-border: #e3e5df;  /* الحدود */
```

غيّر القيمة هنا فينعكس التغيير على الموقع كله. نفس الشي للمسافات (`--space-*`) وأحجام الخط (`--step-*`) ومدد الحركة (`--dur-*`).

### المنتجات والمجموعات
**`assets/data/products.json`** — كل المنتجات والمجموعات من هنا. لا تحتاج تعدّل أي HTML.

حقول المنتج:

| الحقل | الوصف |
|---|---|
| `id` | معرّف فريد، يظهر في رابط المنتج `product.html?id=…` |
| `name` | اسم المنتج |
| `collection` | `running` أو `training` أو `essentials` |
| `price` | `null` = تظهر «السعر قريباً». ضع رقماً عند اعتماد السعر |
| `shortDescription` | سطر واحد يظهر في بطاقة المنتج |
| `description` | الوصف الكامل في صفحة المنتج |
| `sizes` | مصفوفة المقاسات |
| `soldOutSizes` | المقاسات غير المتوفرة (تظهر معطّلة) |
| `colors` | مصفوفة `{ name, hex }` |
| `images` | مصفوفة `{ src, alt }` |
| `featured` | `true` لعرضه في «منتجات مختارة» بالصفحة الرئيسية |

> البيانات الحالية **تجريبية** (`meta.isSampleData: true`) وبدون أسعار عمداً. استبدلها ببيانات منتجاتك الفعلية قبل النشر.

### النصوص والعناوين
مكتوبة مباشرة داخل ملفات HTML (عناوين الهيرو، قصة العلامة، البانر الختامي…). ابحث عن النص وعدّله.

⚠️ الهيدر والفوتر مكرّران في كل صفحة (لأنه ما في build step). إذا غيّرت رابطاً في التنقل، غيّره في الستة ملفات.

### الصور
انظر **`IMAGE_SOURCES.md`** — فيه جدول بكل صورة مطلوبة، أبعادها، مكان استخدامها، وقواعد الترخيص.

الصور الحالية كلها **أماكن مؤقتة** (SVG) وليست صوراً حقيقية.

## ماذا يعمل فعلاً

- ✅ تصفية وترتيب المنتجات (تعمل من البيانات، مع حالة فارغة صحيحة)
- ✅ صفحة منتج بمعرض قابل للتكبير واختيار مقاس ولون
- ✅ سلة تُحفظ في `localStorage` المتصفح، مع عدّاد في الهيدر
- ✅ قائمة موبايل تدعم لوحة المفاتيح و Escape وإرجاع التركيز
- ✅ حركة خفيفة عند التمرير تحترم `prefers-reduced-motion`

## ماذا لا يعمل بعد (بشكل مقصود)

- ❌ **الدفع وإتمام الطلب** — لا يوجد ربط بأي مزوّد تجارة إلكترونية. زر إتمام الشراء معطّل ومكتوب عليه ذلك بوضوح، ولا يوجد أي محاكاة لعملية شراء ناجحة.
- ❌ **الأسعار** — غير معتمدة بعد، فتظهر «السعر قريباً» بدل أرقام مُختلقة.
- ❌ **قنوات التواصل** — صفحة «تواصل معنا» فيها أماكن فارغة معلَّمة، بدون بيانات مُختلقة ولا نموذج مراسلة وهمي.
- ❌ **صفحات الشحن والاستبدال والخصوصية** — غير موجودة لعدم وجود سياسات معتمدة، ولذلك غير مذكورة في الفوتر.

## الخطوة التالية لو حبيت تربطه بـ Shopify

الملفات مبنية بحيث تنتقل بسهولة: بيانات المنتجات كلها في ملف JSON واحد، ومنطق السلة معزول في `assets/js/store.js` (المفتاح `justrun.cart.v1`). استبدال مصدر البيانات بـ Storefront API يحتاج تعديل دالة `loadCatalog` فقط، وربط زر الشراء بـ checkout الحقيقي.
